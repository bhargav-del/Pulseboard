# Security policy

## Supported version

The `main` branch is the supported version of Pulseboard.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Email **yuin39166@gmail.com** with:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested mitigation

You will receive a response as soon as practical.

## Privacy note

This project is designed to work locally in the browser. Do not commit credentials, private payloads, customer data, or API keys.
